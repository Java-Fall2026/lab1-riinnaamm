##  Бенчмарк: Map<String, T> vs List<T> у GenericRepository

| Критерій | `Map<String, T>` (Застосовано) | `List<T>` |
| :--- | :--- | :--- |
| **Пошук за identity `findByIdentity`** | **O(1)** (хеш-таблиця) | O(n) (полінійне сканування) |
| **Перевірка дубліката перед додаванням** | **O(1)** | O(n) |
| **Видалення `removeByIdentity`** | **O(1)** | O(n) |
| **Збереження порядку вставки** | **O(1)** (використано `LinkedHashMap`) | O(1) |
| **Витрати пам'яті** | Трохи вищі (вказівники вузлів хеш-таблиці) | Мінімальні (суцільний масив) |

**Висновок:** Використання `LinkedHashMap<String, T>` забезпечує константну швидкість пошуку та перевірки унікальності O(1), зберігаючи при цьому чіткий порядок додавання елементів.
